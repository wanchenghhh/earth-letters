# 地球来信

先让人被地球的美吸引，再让人看懂它为什么是这个样子。

一次安静的地球旅行：点一下，从太空飞向一个真实的地方，先知道在哪里，再看见它，最后读懂一点。目前有 5 个人工精选的地点。

## 文件

- `index.html`：整个网页，单文件。影像和地球底图已嵌在里面（约 2.5MB）。

## 本地打开

双击 `index.html` 即可。需要联网：三维地球的绘图库 three.js 从 cdnjs 加载。

## 部署到 GitHub Pages

1. 新建一个仓库，把 `index.html` 上传到仓库根目录。
2. 进入仓库的 Settings，找到 Pages。
3. Source 选 “Deploy from a branch”，分支选 main，目录选 `/ (root)`，保存。
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`。

私有仓库能否使用 Pages，取决于你的 GitHub 套餐。

## 注意

- “想多了解一点”（问这张图）只在 claude.ai 的预览页里可用。在 GitHub Pages 上这个按钮不会出现，这是正常的。
- 不要把任何模型密钥写进 `index.html` 或提交到仓库。接入模型需要后端，见开发说明。
- 迪拜这张图的拍摄日期和颜色处理方式尚未核实。
